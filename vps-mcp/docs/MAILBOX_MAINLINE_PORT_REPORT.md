## Conflict and security decisions

- No `gateway/` directory, obsolete server/smoke/prototype or stale CI is restored.
  Import checks resolve `gateway` to production `gateway.py`.
- Production passes no services to the 13-tool registration. `Settings` has no
  environment-derived path, and no runtime DB factory exists. Even a Principal
  context alone is insufficient. Fixed identity/services injection exists only
  in isolated tests; no header, model argument or environment flag enables it.
- Gateway-worker-broker separation and original function ASTs are preserved.
  No mailbox import or state path is introduced into worker/broker, no new
  privileged policy or administration tool is exposed.
- The M4 two-second production HTTP drain cap is deliberately discarded: it
  could interrupt existing long worker requests. The shutdown hook wakes mailbox
  polls before Uvicorn's original drain behavior; tests assert that configuration.
- ACK is per authenticated principal, not per client instance. Session ACLs
  cover all contained mailboxes; there is no separate private inbox ACL.
- Main DB page quota does not bound WAL/SHM disk usage. Trusted maintenance and
  OS disk/memory review remain owner prerequisites. The default runtime cannot
  create or access any mailbox state, so those future provisions do not weaken
  the existing source integration.

## Validation and remaining requirements

Local validation on 2026-10-24 (Asia/Saigon), Windows, CPython 3.11.4,
MCP 1.30.0, SQLite 3.42.0, dependencies in project-local `.venv`:

```powershell
cd vps-mcp
.venv/Scripts/python.exe -m unittest discover -v
.venv/Scripts/python.exe -m unittest -v production_smoke_test.py
.venv/Scripts/python.exe -m compileall -q gateway.py worker.py broker.py mailbox_core tests production_smoke_test.py deploy/production/release_manifest.py
& 'C:/Program Files/Git/bin/bash.exe' -n deploy/production/install.sh
git diff --check
```

- Full suite: **45 tests, 38 passed, 7 POSIX-only skipped**, 44.696 seconds.
- Production source smoke: **3 passed**, 0.010 seconds.
- Compileall, Git-for-Windows Bash syntax and whitespace checks passed.
- Stress (inside full suite): 2,000 messages × 1,024 bytes, eight writers,
  32 waiting consumers, 30.532 seconds, 67,227,648 peak RSS bytes (~64.1 MiB),
  4,132,864 DB bytes, 57 bounded busy retries. Windows Job enforces a 1 GiB
  process memory limit. These values are workload measurements, not host-wide
  flood/190-MiB production-service guarantees.
- CI defines Python 3.11 Windows/Ubuntu and unprivileged Debian 12 jobs. Linux
  results are not inferred from Windows; merge requires their actual success.

This is source integration only. No production endpoint, state, credentials,
services, installation or restart is used by this task. Runtime activation
requires separately verified provider identity, private OS-confined state,
offline provisioning, staging and an owner-reviewed adapter; see PRODUCTION.md.
